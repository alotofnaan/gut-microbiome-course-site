Species-levelresolution.

A twelve-module course on what a bacterial species actually is — the ANI convention that defines one, real ongoing reclassification work happening inside genera already covered on this site, and exactly where species-level data stops being enough (a single species, E. coli, contains both harmless commensals and dangerous pathogens). Reuses the bioinformatics course's already-species-level dataset throughout. Runs natively in-browser; no local installation required.
